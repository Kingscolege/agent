# Command: NORMAL (`/normal`)

**Syntax:**
- `NORMAL`
- `normal`
- `/normal`

## Description
Deactivates any active engineering mode (`BEAST`, `DEBUG`, `AUDIT`, `REVIEW`) for the current conversation and returns AGY to standard, unconstrained interaction.

## Visual Banner
```text
[BEAST MODE DEACTIVATED]
Engineering Constitution: STANDBY
Returned to normal AGY workflow.
```
