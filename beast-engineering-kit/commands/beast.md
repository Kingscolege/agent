# Command: BEAST (`/beast`)

**Syntax:**
- `BEAST`
- `beast`
- `/beast`
- `BEAST: <task>` / `beast <task>`

## Description
Activates the full, production-grade 12-step software engineering methodology for the current conversation.

## Workflow
1. **Repository Reconnaissance:** Automatic stack, lockfile, and gate discovery (`repo-intelligence`).
2. **Requirements Analysis:** Specification and Given/When/Then acceptance criteria (`spec-driven-development`).
3. **Root-Cause Investigation:** 4-phase debugging (no symptom patching) (`systematic-debugging`).
4. **Architecture & Impact Analysis:** Architectural Decision Records (`ADR`).
5. **Implementation Planning:** Bite-sized 2–5 min atomic verifiable steps (`writing-plans`).
6. **Skill Discovery & Activation:** Explicit loading of domain skills.
7. **Intelligent Agent Delegation:** Context-isolated subagent dispatch (`subagent-driven-development`).
8. **Implementation via TDD:** Red-Green-Refactor cycle (`test-driven-development`).
9. **Automated Testing & Validation:** Full execution of `./verify.sh`.
10. **Independent Code Review:** Multi-angle review across Logic, Concurrency, Security, Perf (`code-review-lead`).
11. **Security & Anti-Slop:** Vulnerability audit (`security-audit`) and diff-scoped cleanup (`deslop`).
12. **Verification Before Completion:** Evidence-backed verification handoff (`verification-before-completion`).
